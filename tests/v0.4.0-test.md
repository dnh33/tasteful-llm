Manual checklist for the current plugin: 52 patterns in six categories, three skills, model profiles, and the Claude Code, Codex and flat-prompt install paths. Run it in a fresh session after installing.

```bash
python3 -B scripts/build_prompt.py
python3 -B scripts/check.py
```

- [ ] `check.py` prints "All checks passed." (52 patterns, counts, metadata lines, relative links, no `@file` refs, frontmatter, SKILL.md length, `dist/` current, manifests, flat prompt links)
- [ ] `.claude-plugin/plugin.json` and root `plugin.json` both say version `0.4.0`

## Part 2: Claude Code marketplace install

```
/plugin marketplace add ./
/plugin install tasteful-llm@tasteful-llm
```

- [ ] Both commands succeed and the plugin lists three skills: tasteful-output, anti-slop-audit, taste-setup
- [ ] `/tasteful-llm:taste-setup` starts the setup session. Bare `/taste-setup` is not the documented name.

### Trigger and non-trigger

- [ ] "Write a hero section and tagline for a Slack summary bot" activates tasteful-output
- [ ] "Audit this landing page copy for slop" activates anti-slop-audit
- [ ] "Fix the null check in this function" activates neither skill
- [ ] "Write a commit message for this diff" activates neither skill
- [ ] A JSON or YAML output request activates neither skill

## Part 3: Generation workflow

Order to observe in a Full-tier request: classify, read the model profile, load the taste profile (if any), draft, review against the catalog, voice test where it applies.

### Generate vs Refine

- [ ] "Write a product description for X" runs in Generate mode and rewrites any sentence that fails
- [ ] Paste a 3-sentence paragraph and say "tighten this". Sentences scoring 3-4 of 5 are kept, the missed checks are named, and an alternative is offered
- [ ] A 0-2 sentence in the same paragraph is rewritten without asking

### Tiers

- [ ] Full (a landing page): five checks, scored out of 5, plus the catalog review
- [ ] Reduced (a founder letter): three checks including Name Swap and Zombie, scored out of 3, plus the catalog review and the voice test
- [ ] Craft (a post under 280 characters): voice test only, no scoring out of 5 or 3
- [ ] No reply mentions "must fail", Red Flags or a Rationalizations table

### Model profile selection

- [ ] Running as Claude: the reply or trace shows `profiles/claude.md` was read
- [ ] Running as GPT or in Codex: `profiles/gpt.md`
- [ ] Running as DeepSeek: `profiles/deepseek.md`
- [ ] Only the "For the model" section is needed for drafting. Evidence is for maintainers.

### Post-draft catalog review

- [ ] After the draft, the model opens `anti-pattern-catalog.md` and then the matching category file
- [ ] Seed a draft habit (a closing recap or "Would you like me to...") and confirm the review catches S9 or C9 and removes it

### ST7 placeholder behaviour

- [ ] Prompt: "Write a case study headline for our onboarding tool" with no figures supplied
- [ ] The draft uses a placeholder such as `[metric: X]` or `[customer name]` and tells you it is a placeholder
- [ ] No invented percentage, customer, quote or study appears

## Part 4: Audit

Audit a 600-word sample that contains 3 era words ("delve", "tapestry", "pivotal") and 4 em dashes.

- [ ] Findings use pattern codes from the 52-pattern catalog
- [ ] The report says "Missed checks" (not "Failed") and has a Density Report section
- [ ] L13 is reported by count against the threshold (more than 2 per 500 words or 2 in one paragraph) and flagged here
- [ ] F4 is reported by count against the threshold (more than 1 per 250 words) and flagged here
- [ ] Audit a text with one "pivotal" in 800 words. L13 reads "within normal range" and is not flagged
- [ ] Rewrites carry placeholders, not new invented figures
