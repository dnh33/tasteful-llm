# Anti-pattern catalog: 52 patterns in six categories

Index of all named slop patterns: 17 language (L), 10 structure (S), 9 copy (C), 7 strategy (ST), 5 design/UI (D) and 4 formatting (F). Use it as a post-draft review pass: write the draft first, then check it against the relevant category file for full examples and fixes. Each pattern is described by the move it makes, so other wordings of the same move count. Every pattern carries one metadata line, `Status: <value> · Seen in: <models or "all"> · Verified: <month>`. The status is consistent, rising, fading or unchecked. Unchecked means the original pattern was not re-verified in 2026-10.

| Code | Pattern | One-Liner |
|------|---------|-----------|
| L1 | Adjective Crutch | Stacking modifiers where one fact would do |
| L2 | Fortune-Cookie Close | Dramatic ending that could close any pitch about anything |
| L3 | Thesaurus Parade | Three synonyms in a row; also the tricolon reflex (three items where the content has one or two) |
| L4 | Weasel Hedge | Four layers of insulation between the claim and any commitment |
| L5 | Breathless Opener | "In today's..." throat-clearing before the point |
| L6 | Enthusiasm Proxy | Your excitement replacing the reader's interest |
| L7 | Empower/Unlock/Leverage | Abstract verbs replacing literal descriptions |
| L8 | False Binary | "Either the old way or our product" hiding all alternatives |
| L9 | Anthropomorphized Product | "Our platform understands", when software processes |
| L10 | Consensus Appeal | "Everyone knows..." to skip proving the claim; also vague authority ("experts argue") with no named source |
| L11 | Temporal Urgency Fake | "Now more than ever", always true and never meaningful |
| L12 | Hollow Contrast | The contrast-reframe family: "not just X but Y", "more than a X", "rather than simply" |
| L13 | Era Vocabulary | "Delve", "tapestry", "pivotal", "underscore": flagged at more than 2 era words per 500 words, or 2 in one paragraph |
| L14 | Trailing -ing Gloss | ", ensuring alignment and fostering..." clauses that claim significance |
| L15 | Significance Inflation | "A testament to", "marks a pivotal moment", "evolving landscape" |
| L16 | Copula Dodge | "Serves as", "stands as", "boasts" where "is" or "has" is meant |
| L17 | Importance Flag | "This matters", "here's the thing", "crucially": announcing importance instead of showing it |
